Collect the following about the application, one topic at a time:
1. Confirm the application's name.
2. Business owner (accountable person or team; prefer a user reference such as `user:<id>`).
3. Technical owner — mandatory if criticality is high.
4. Approximate number of users.
5. Criticality: low, medium or high (ask what happens if it is unavailable for a day).
6. Main technologies.
7. Interfaces to other applications (use their names as known in this cycle).
If the person has approved data from a previous cycle, offer to start from it and ask only what changed.
