# ADR-0001: Record architecture decisions and assumptions as ADRs

* Status: accepted
* Date: 2026-11-20

## Context
The mission asks to work autonomously and record every unclear point and dependency choice.

## Decision
Lightweight ADRs (Context / Decision / Alternatives / Consequences, exit path) in
`docs/decisions/NNNN-title.md`. Dependency ADRs are short and grouped by concern.

## Consequences
Every deviation from MISSION.md or ARCHITECTURE.md needs an ADR.
